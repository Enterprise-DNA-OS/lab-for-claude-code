# Why a database and commands

The weekly work is reading records, identifying overdue tests, reviewing evidence and preparing paperwork. A database plus a coding agent handles those jobs without a web application. Read-only HTML gives the bench and manager a view they can print.

A screen also gives touch entry, barcode capture, instrument connections, role-aware approval buttons and mobile workflows. This free base has none of those interactions. Local mode works on one computer, but it is not offline synchronisation between devices. The documents are snapshots, not live screens.

Enterprise DNA builds the capture screens, instrument connections, customer portal and access controls around your intended use. Shared deployment needs identity, database permissions, backups and laboratory validation. A draft certificate never becomes an accredited report simply because a result has a recorded review.
